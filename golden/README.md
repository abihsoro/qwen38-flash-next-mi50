# golden/ — reference traces (I4-protected)

Filled by task **S3**: traces for ≥ 8 fixed inputs, generated by extracting the
same layer slice from the checkpoint and running it on CPU in fp32 in the guest.

- [I4] Changes to these traces require human decision **H6** recorded in
  `DECISIONS.md`. Never regenerated casually.
- `harness/verify.py` (S3) checks kernels against these traces and must fail on
  a deliberately perturbed kernel (negative control).
